# Design system

## Colour

| Token | Hex | Use |
| --- | --- | --- |
| Navy | `#07111f` | Base background |
| Teal | `#14b8a6` | Control, safety, progress |
| Cyan | `#22d3ee` | Default accent, links, focus |
| Amber | `#f59e0b` | Highlights, the rising sun, caution |
| Red | `#ef4444` | Warnings, risk, capability |
| Blue | `#3b82f6` | Labs, research, forecasts |
| Lime | `#84cc16` | Success, policy, flourishing |

There is no purple or pink anywhere. The accent can be switched to any of the six colours, and there are dark, light and high contrast themes.

## Type

Space Grotesk for headings, Instrument Serif italic for emotional lines and quotes, Inter for body text, JetBrains Mono for data, years and labels.

## Motion

Canvas particle fields in the hero and scroll story, word by word reveals, Ken Burns covers, animated SVG flows in the AI control diagrams and branch map, and page transitions with the View Transitions API where supported. Everything respects reduced motion and the Motion switch in settings.

## Brand

The mark is a doorway on a horizon with a rising amber sun inside it. A threshold is the line you cross between one room and the next. The logo is plain SVG in `assets/brand/`.
