## 01 What it is

A threshold is a doorway. You stand on it for a moment, and then you are in a different room. That is where we are with AI. The people who built modern AI are now warning, in public and with numbers, that machines smarter than us may arrive within years, and that we do not yet know how to control them.

**Threshold** is one route of the open source ASI hub. It puts those warnings in one calm place, with every quote linked to where it was said, explains the core ideas in simple words, and then gives you things to do: steer the futures, play the blue team, take the course, tick the checklist, use the tools. It is made by Aniruddha Adak and built with Hark, and it follows the repo motto: start big, fix later, keep shipping.

### Why it stays static instead of moving to React or Next

I kept Threshold as plain HTML, CSS and ES modules on purpose. GitHub Pages serves it as is under `/ASI/future-of-asi/` with relative URLs, so there is no build step to break and anyone can fork it and edit one file. Hash routes mean every deep link works without server rewrites, which Pages does not offer. A service worker plus a generated file list gives full offline reading, which is simpler to reason about without a bundler renaming files. Each view is one module loaded on demand, so the first paint stays small without a framework runtime. The blank view bug was a routing and caching problem, not a framework problem, so I fixed the router and the cache instead of rewriting everything.

```mermaid
flowchart LR
  NAV[core/nav.js one header] --> APP[index.html hash app]
  NAV --> SUB[explosion/ and library/]
  APP --> R[router with view transitions, progress bar, prefetch, error boundary]
  R --> V[views/*.js and views/extra/*]
  GEN[raw/gen/offline_manifest.py] --> OM[offline-manifest.json]
  OM --> SW[sw.js precache core]
  OM --> SAVE[Save everything for offline]
```

## 04 Deep dive

### The futures model

The six futures are stories written for this guide, not predictions. Each scenario carries a weight for each lever. The page turns slider positions into a score per scenario, then a softmax turns scores into shares, with a small floor so no future ever disappears. That is enough to show direction: race pressure feeds The Race and Catastrophe, coordination and public awareness feed The Slowdown, AI control feeds Controlled Takeoff, and alignment progress feeds Flourishing.

```mermaid
flowchart LR
  S1[Race pressure] --> M((toy model))
  S2[Takeoff speed] --> M
  S3[Alignment progress] --> M
  S4[AI control in labs] --> M
  S5[Global coordination] --> M
  S6[Public awareness] --> M
  M --> C1[Coordinate: Flourishing, Slowdown]
  M --> C2[Control: Controlled Takeoff]
  M --> C3[Compete: Many Hands, Race, Catastrophe]
```

### The blue team game

The game follows the shape of Redwood Research's 2023 AI control experiments in a simplified form. Three of forty tasks hide a real backdoor in the code. A trusted monitor gives noisy suspicion scores. An untrusted monitor is sharp but colludes, scoring real attacks as clean. With honeypots on, you plant fake attacks, and if the monitor scores one low you can expose it. You win by auditing a real backdoor, by exposing collusion, or by finishing the shift with nothing shipped.

```mermaid
sequenceDiagram
  participant U as Untrusted model
  participant M as Monitor (T or U2)
  participant You as Blue team
  participant H as Human audit
  U->>M: code for task n
  M->>You: suspicion score 0 to 10
  alt score is high and budget left
    You->>H: audit
    H-->>You: clean, or backdoor caught
  else grey zone
    You->>You: defer to trusted model
  else looks fine
    You->>You: accept and ship
  end
  Note over You,M: With honeypots, a monitor that scores a planted attack low exposes itself
```

### The p(doom) calculator

It uses the six premise chain from Joe Carlsmith's report [Is Power-Seeking AI an Existential Risk?](https://arxiv.org/abs/2206.13353). The report's own numbers were 65%, 80%, 40%, 65%, 40% and 95%, about 5% by 2070, and the abstract notes his estimate later rose above 10%. You can load those numbers with one click, set your own, and tick arguments that nudge the result in log odds. The tool then shows which stated views in the dataset sit closest to yours.

| Concern | How it is handled |
| --- | --- |
| Routing | Hash routes, so every deep link works on GitHub Pages under `/ASI/future-of-asi/` with relative URLs |
| Views | One ES module per page, imported on demand, each returns a cleanup function |
| Sub paths | Drawers, theater player, lessons and tools update in place through `el._onParams` |
| Transitions | View Transitions API where supported, with a CSS fade fallback |
| Search | One index built on first open from all datasets, multi word, ranked |
| Storage | `localStorage` keys prefixed `thr:` for prefs, course, checklist, history, tool settings |
| Offline | Service worker precaches the core list from `offline-manifest.json`, code and data network first, images cache first, YouTube posters capped, videos never cached |
| SEO | Title, description, canonical, Open Graph, Twitter card, JSON-LD WebSite and Course, sitemap of 128 deep links |

<a id="09-run-and-contribute"></a>

## 09 Run and contribute

```
git clone https://github.com/lo3elyon/ASI.git
cd ASI
python3 -m http.server 8000
# open http://localhost:8000/future-of-asi/
```

There is no build step. Edit a JSON file or a markdown post and reload. The rules for contributions are simple: never invent a quote, number, date or video ID; write in simple words; no em dashes and no exclamation marks; no purple or pink; and show disagreement fairly. Verify a YouTube ID with `https://www.youtube.com/oembed?url=https://www.youtube.com/watch?v=ID&format=json` before adding it.

<a id="11-questions"></a>

## 11 Questions

**Is this saying AI will kill everyone?** No. It shows what many serious researchers warn about in their own sourced words, and it also shows people who disagree.

**Are the futures predictions?** No. They are stories for thinking, and the sliders drive a toy model that shows direction, not probability.

**Is my progress sent anywhere?** No. Course progress, the checklist, watch history and tool settings stay in your browser.

**Does it work offline?** Yes. After the first visit every page, both deep dives and the library open offline. Press Save everything for offline in the You menu to keep all photos, covers and snapshot pages too. Videos still need a connection.

**Can I use the data?** Yes. It is plain JSON in `data/`. Quotes belong to their speakers, and photos keep their Wikimedia Commons licences, credited in each profile.
